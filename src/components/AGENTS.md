# src/components

Shared UI for every feature. The look is fixed by [design.md](../../design.md) and the specs [0003](../../docs/specs/0003-design-system-and-ui-foundation/index.md) (tokens, components, shells) and [0004](../../docs/specs/0004-type-and-layout-refinement/index.md) (font, type scale, canvas and zones). Where the two disagree, 0004 wins.

## Where things live

- `ui/`: shadcn/ui components on Radix, generated by the CLI and then edited once. Treat them as our source.
- `states/`: shared states (`EmptyState`, `LoadingState`, `ErrorState`, `RateLimitNotice`, `NotFoundState`, `ForbiddenState`, `ImagePlaceholder`, `RouteError`). Copy for an empty state comes from the feature.
- `form/`: `FormField` (React Hook Form plus the shadcn `Field`, with ids and `aria-*` wired) and `FailureNotice` (the form level server error).
- `layout/page-header.tsx`: `PageHeader`, the one `h1` of a page.
- `shells/`: the page frames (`PublicShell`, `AuthShell`, and `WorkspaceShell`, which `LandlordShell` and `AdminShell` use), the account menu and `nav-config.ts`.
- `list-pagination.tsx`: page links from `{ page, pageSize, total }`.
- `../hooks/use-mobile.ts` comes with the sidebar component.

## Rules

- Semantic tokens only (`bg-primary`, `text-muted-foreground`). No raw color. Values live in `src/app/globals.css`, and a new text or control color pair must be added to `scripts/check-contrast.mjs` in the same change.
- Add a shadcn component with the CLI, one at a time (`npx shadcn@latest add <name>`, never `--all`, never `--overwrite` without approval). Then apply the edits listed in spec 0003 ("Edits after adding shadcn files"): focus ring, `overlay` token for backdrops, Vietnamese labels, sizes, no `dark:` classes.
- `className` is for layout, not for restyling. Use the variants and sizes a component already has.
- Every visible and screen reader string is Vietnamese. Icon only buttons have an `aria-label`. A dialog, sheet or alert dialog always has a title (`sr-only` if hidden).
- Control heights are 32, 40 and 44 px. Public pages use `size="lg"` at every width. The focus ring comes from `FOCUS_RING` in `src/lib/focus-ring.ts`.
- Text weights are 400, 500 and 600 only. A page area is a `Card` zone on the `canvas` background, and a card never sits inside another card.
- Shells stay static: no `cookies()` or `headers()` in a shell, and a client leaf that reads `usePathname` sits inside `<Suspense>`. A feature adds its link to `nav-config.ts` in the same change that ships its page.
- Open a dialog through its trigger component. A dialog driven only by state (`open={...}`, no trigger) dropped focus to `body` when it closed in the spec 0003 verify run, and the sample screens for my listings and admin users still do this.

## Living reference

`/dev/ui` shows every component, state and shell, and `/dev/ui/screens` shows seven sample screens on fake data. Both answer 404 in production. A feature that ships one of those screens lifts its markup and `PageHeader` instead of drawing it again.
